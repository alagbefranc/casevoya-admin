# casevoya-admin

Platform operations console for Casevoya, served at `admin.casevoya.ca`.

Casevoya is software only. This console is for running the platform (firms, delivery health,
service notices, support access). It publishes no immigration content, and it has no
licensed-review step: each firm's own licensed members build and approve their own templates
inside the main app.

See the scaffold PR for the full README.
