## What is there
- Title: "Free Charts for Better Data Visualization", by Keitoto Studio. 62 chart cards, mostly finance and dashboard widgets (budget, balance, cash flow, trends).
- Clicking a card opens a modal with Preview and Code tabs, a FREE badge, "Download .fig" and "Copy AI prompt".
- The code, the .fig file and the AI prompt are gated: "Register to get this freebies… free with a mebius account" (Google, GitHub, X or email). See mebius/code-*.txt. **I didn't sign up**, so I got no code or Figma files.
- License page: $19 per item or $259 for the bundle. Commercial SaaS use is allowed. Redistributing the files or repackaging them as UI kits or design systems is forbidden.
